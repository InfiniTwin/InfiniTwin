# IFC5 Viewer (Unreal Engine + Flecs)

This repository contains an experiment with an **IFC5 viewer** built in **Unreal Engine** using **[Flecs](https://github.com/SanderMertens/flecs)**.

Since [IFC5](https://github.com/buildingSMART/IFC5-development) is being developed around **ECS principles**, Flecs is a natural fit.  
It enables modularity, composition, collaboration, and high performance directly within BIM workflows.  
Flecs also provides features such as relationships, inheritance, hierarchy trees, Prefabs, the Flecs Query Language, the Flecs Script DSL, browser support, and more.

This approach shows how IFC5 can move beyond static formats toward a system where data can be queried, composed, and interacted with in real time.  
Combined with Unreal Engine’s real-time rendering, multi-platform support, and AR/VR capabilities, this provides an early look at a possible next step for BIM tooling.
